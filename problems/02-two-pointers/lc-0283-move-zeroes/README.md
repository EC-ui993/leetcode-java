# lc-0283 移动零

## 思路

慢指针left = 下一个该放非零元素的位置，快指针right = 非零元素的位置，直到快指针找到数组最后一个就说明整个数组处理完成

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 解法演进

有思路之后用的是双指针

## 踩坑

刚开始的解法，直接遇到0就和后面的数字换位，但是忽略了相对位置不变的要求，
后面改成快慢指针找到非零元素后让非零元素和0交换位置，这样就符合题目要求了
