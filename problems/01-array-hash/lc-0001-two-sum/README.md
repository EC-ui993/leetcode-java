# lc-0001 两数之和

## 思路

暴力解法直接把所有数字两两结合枚举就可以，但是时间复杂度会到O(n²)，可以把问题转化为需要什么数字，然后
在哈希表里找需要的数字是否存在(O(1)时间复杂度)，存在找到，不存在存入当前数字，这样时间复杂度就变成了O(n)

## 复杂度

- 时间 O(n)（一次遍历），空间 O(n)（最坏存满）

## 解法演进

- 先想到暴力两两枚举 O(n²)，发现内层其实在问"target-x 在不在"，
  这才换成哈希表。没试排序，因为要返回原下标。
- 只哈希一次:
            Integer j = map.get((need));
            if (j != null) {
            return new int[] { j, i };
            }


## 踩坑

- 一开始写成先全部入表再遍历，[3,3] target=6 会返回 [1,1]——
  同一个元素用了两次。改成边查边存就对了。
