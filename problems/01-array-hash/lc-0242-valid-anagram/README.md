# lc-0242 有效的字母异位词

## 思路

字母异位词每个字母出现的种类和次数是一样的，只需统计次数，最后检查即可

## 复杂度

- 时间：O(k)
- 空间：O(1)

## 解法演进

最开始使用排序对比的方法，时间复杂度是O(klogk)，因为排序需要时间。后面看了题解使用建长度为26的表来统计每个字母出现的次数和种类，这样时间复杂度变成O(k)，空间复杂度变成O(1)，直接建表了。开头的比较长度间接排除了>0的情况，因为长度相同的情况下有>0的就必然有<0的。

## 踩坑

没想到数组要怎么处理，要怎么存字母，原理是以s.charAt(i) - 'a' 为下标，从0到25
